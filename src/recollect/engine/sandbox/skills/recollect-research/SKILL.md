---
name: recollect-research
description: How to find and verify external facts during delegated web research. Not needed for files built only from facts you were given.
---

<steps>
1. Identify the entity and its official website from search results or sources that link to it. Don't guess a domain.
2. Fetch the page behind each important claim.
3. Check dates, units and qualifiers. Keep each URL with the fact it supports.
4. Report each verified fact as a finding right away.
5. Finish with the supported answer and name any specific fact you could not verify.
</steps>

<rules>
- Missing search results, a parked page or a guessed domain don't prove an organization is absent or inactive.
- If web search is failing, unrelated scholarly hits don't verify a company. Try a relevant public index or a known source; if that fails too, report the access problem.
- For a named comparison, verify both entities and the claimed overlap.
- Separate inference from evidence. Leave out unsupported entries rather than fill a requested count.
- If changing both the source and the fetch view gets nowhere, report blocked.
</rules>
